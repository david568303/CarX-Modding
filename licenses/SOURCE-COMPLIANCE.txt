   dbda1cb353b0f4253345dc45136d170b9e50a5a0

source-manifest.json records source archive URLs, exact commit identifiers,
SHA-256 hashes, and required build files. The upstream source archives
contain their original build projects, scripts, declarations and reference
assemblies; no CarX executable, copied game metadata or generated CarX
interop is added to them. Independent dependencies retain their own terms.

BUILDING REPLACEMENTS

Use an existing Visual Studio C++ toolchain and .NET SDK. No compiler needs
to be installed by this project. Extract the source ZIPs to separate build
folders. Keep all upstream files, including NuGet configuration and reference
assemblies. Restore the dependencies declared by the upstream projects from
the upstream configured feeds. Read each archive's README and build projects
for its supported SDK and configuration.

BepInEx's Unity IL2CPP project is:
  Runtimes/Unity/BepInEx.Unity.IL2CPP/BepInEx.Unity.IL2CPP.csproj
Its repository root includes BepInEx.sln and the build/ Cake Frosting project.
Build that project/solution with its existing configuration; upstream build
scripts provide packaging and version generation. The IL2CPP output includes
BepInEx.Core, Preloader.Core, Unity.Common and Unity.IL2CPP.

Il2CppInterop's repository root includes Il2CppInterop.sln and projects for
Common, Generator, Runtime and HarmonySupport. Build its solution or the
required projects in Release with dotnet build. Version-stamping settings
affect the informational version; ABI-compatible replacements need not be
byte-for-byte identical to the original build.

To rebuild this project's Doorstop and managed bootstrap use BUILD.txt in
../source.zip. The Python scripts are shipped as editable source directly.

INSTALLING REPLACEMENTS

Close the game. Replace winhttp.dll with the rebuilt Doorstop DLL. Replace
the corresponding BepInEx or Il2CppInterop DLLs under BepInEx/core with
your compatible rebuilt versions. Replace the managed metadata bootstrap
and Python scripts at the locations described in source.zip/BUILD.txt.
Retain the installation layout and public interfaces required by the other
components. Start the game normally to load your replacements.
