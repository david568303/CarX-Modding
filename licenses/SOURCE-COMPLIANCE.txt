CORRESPONDING SOURCE AND REPLACEMENT INSTRUCTIONS

SOURCE-DOWNLOADS.txt at the root of the runtime ZIP identifies the complete,
corresponding source revisions for the modified UnityDoorstop fork, BepInEx,
Il2CppInterop, Capstone and Dobby. The CarX-Modding revision includes the
compatibility source, build tools, and patches needed to rebuild the release.
The explicit source asset on GitHub also expands the UnityDoorstop submodule.
The upstream components keep their original licenses.

BUILDING REPLACEMENTS

Follow the pinned build instructions linked in SOURCE-DOWNLOADS.txt.
Use an existing Visual Studio x64 toolchain, CMake and a .NET SDK. For
BepInEx and Il2CppInterop, use the pinned upstream project files and feeds.
For the Capstone and Dobby builds, use the patches and build scripts in
the CarX-Modding source. ABI-compatible replacements need not be identical
to the original builds byte for byte.

INSTALLING REPLACEMENTS

Close the game. Install compatible rebuilt versions at their runtime paths:
  winhttp.dll
  BepInEx/compatibility/capstone.dll
  BepInEx/core/BepInEx.MetadataBootstrap.dll
  BepInEx/core/ (other BepInEx, Il2CppInterop and Dobby DLLs)
Start the game normally to load your replacements.

This project allows modifying and replacing LGPL components and reverse
engineering needed to debug those modifications. It imposes no signature
gate on replacement libraries.

REDISTRIBUTION

Retain the full licenses, attribution and source information. If you
redistribute a modified LGPL component, provide complete corresponding
modified source and build/install instructions under the applicable
LGPL. Keep equivalent access to source beside the distributed binaries.
